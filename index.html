정면 기준은 얼굴의 방향이며, 실제 눈동자 시선이나 몰입 상태는 측정하지 않습니다.

테스트 제어

등록된 정면 기준: 0개 · 기본 기준 사용 중

작업할 때의 자세마다 ‘정면 기준 추가’를 눌러 주세요. 등록한 기준 중 하나와 일치하면 정면으로 판정합니다. 기준은 이 기기·브라우저에 저장하여 새로고침하거나 다시 접속해도 재사용합니다. ‘기준 초기화’를 누르면 저장된 기준도 삭제합니다. 카메라 위치를 바꾸면 초기화 후 다시 등록하세요.

소리·음량·확인 간격은 이 브라우저에 자동 저장됩니다.

어떤 소리가 기분 좋은가요?

버튼을 누르면 소리를 선택하고 바로 미리듣습니다. 카메라 없이도 비교할 수 있습니다. 초침 외 소리는 약 1.4초간 재생하며, 정면 감지 때도 선택한 소리가 납니다.

확인 순간 직전 약 1초간 정면 상태가 안정적으로 유지되어야 소리가 납니다. 고개를 돌리거나 얼굴이 사라지면 울리지 않습니다.

카메라를 자동으로 시작합니다. 카메라 권한을 허용해 주세요.

사용 방법

  1. 아이폰 Safari에서 HTTPS 주소로 접속합니다. (맥에서는 localhost도 가능)
  2. 페이지를 열면 카메라 시작을 자동으로 시도합니다. 전면 카메라 권한을 허용하세요. 자동 시작이 제한되면 카메라 시작을 누르세요.
  3. 자동 시작 후에는 선택한 소리 다시 듣기나 사운드 미리듣기 버튼을 한 번 눌러 소리를 활성화하세요.
  4. 폰을 책상에 세워 놓고, 작업할 때의 자세에서 정면 기준 추가를 누릅니다. 다른 작업 자세도 같은 버튼으로 추가할 수 있습니다.
  5. 원하는 사운드를 선택하고, 얼굴을 좌우로 돌렸다가 등록한 자세로 돌아오며 소리를 확인합니다.
  6. 테스트를 마치면 정지를 눌러 카메라를 종료합니다.

브라우저 보안 정책으로 파일 앱에서 HTML을 직접 여는 방식(file://)은 카메라가 작동하지 않을 수 있습니다. HTTPS 웹사이트로 배포해 테스트하세요. 화면이 잠기거나 Safari가 백그라운드로 이동하면 카메라 분석이 중지될 수 있습니다. 영상은 기기에서 처리하며 서버로 업로드하지 않습니다. 단, 얼굴 인식 라이브러리는 처음 실행 시 CDN에서 내려받습니다.
